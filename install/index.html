iPhone'a Ücretsiz Kur Safari ile Aç / Ana Ekrana Ekle
Kurulum (APK'ye en yakın yöntem):
1. Sarı iPhone'a Ücretsiz Kur düğmesine dokunun.
2. Profil indirme iznini onaylayın.
3. Ayarlar → Profil İndirildi (veya Genel → VPN ve Aygıt Yönetimi) bölümünü açın.
4. Yükle deyin ve ekran kilidi kodunu girin.
5. ROTA simgesi ana ekrana gelir.

Profil kullanmak istemezseniz: Safari ile açın → Paylaş → Ana Ekrana Ekle → Web Uygulaması Olarak Aç.
